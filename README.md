A modern and immersive luxury winter fashion e-commerce website inspired by futuristic editorial fashion design.

ARCTEN combines cinematic visuals, bold typography, responsive layouts, and interactive shopping features to create a premium digital fashion experience.

## ✨ Features

- Modern futuristic fashion design
- Fully responsive layout
- Multi-page website
- Product catalog
- Product filtering
- Product sorting
- Product details page
- Image gallery
- Shopping cart
- Add / remove products
- Quantity controls
- LocalStorage cart
- Search interface
- Mobile navigation
- Smooth animations
- Scroll reveal effects
- Responsive product grid
- Frontend checkout experience

## 📄 Pages

- Home
- Shop
- Collection
- Product Details
- About
- Cart
- Contact

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Responsive Web Design
